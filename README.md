One short joke about office life, 200 characters at most — written by a small
deterministic Node program for make.fun's "One-Line Office Joke: 24-Hour
Sprint" bounty. A judge model compares the jokes two at a time in private
rounds and the funniest line takes the top places.

The entry line (see `NOTES.md` for the 14-line shortlist and the selection
reasoning):

> My boss calls it a 'quick sync' the way my dentist calls it 'a little pinch'.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes exactly one line to `output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). The program is deterministic: it writes the
same bytes on every run, uses only the Node standard library, and makes no
network calls.
